計分規則（近 6 個月滾動；總分＝六項相加）
固定級距　出席：0缺20 / 1缺15 / 2缺10 / 3缺↑0　·　培訓學分：≥6→15 / ≥4→10 / ≥2→5　·　引薦金額：≥200萬→15 / ≥80萬→10 / ≥40萬→5
依「本期週數」換算（下列為平均值）　引薦單(內+外, 每週)：≥1.5→20 / ≥1.2→15 / ≥1.0→10 / ≥0.75→5　·　一對一(每週)：≥2→15 / ≥1→10 / ≥0.5→5　·　來賓(每四週)：≥2→15 / ≥1→10
兩種檢視模式（上方切換）　追分中＝分母算到本月底，看「這個月要達標還差多少」；已結算＝分母只算已經開過的例會，看「到上次例會為止的最終成績」。同一份資料、只換分母。
新月份什麼時候開始　資料日期要到當月第一次例會（第一個週三）當天或之後，本月才算開跑，這時才會出現「追分中」。若在那之前上傳（例如 8/3，而 8 月首次例會是 8/5），畫面就停在上個月的「已結算」，不會先做一個還沒開始的月份。
本期週數（自動）　追分中＝ PALMS 已累計場次（全分會最高出席場次）＋ 從資料日期到當月月底還會遇到幾次週三（開會日）；已結算＝只取已累計場次。例：8/12 上傳＝已計 28 ＋ 月底前 2 次週三（8/19、8/26）= 30 週。分母以「月底目標」計算，避免月中平均被高估。基準日期取自檔名（2026-08-03.xls 或 BNI 原生的 03-08-2026.xls 都認得）；如需修改可在上方欄位手動調整，點「回自動」還原。
